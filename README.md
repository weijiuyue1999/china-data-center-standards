# 中国数据中心标准规范政策查询库

面向中国区域数据中心工程设计、建设、验收和运行评价的交互式查询工具。支持按标准、专业方向、指标、房间和单位筛选，并可跨标准检索荷载、净高、PUE、消防、温湿度、施工验收、成熟度等要求。

在线版本发布于 GitHub Pages。离线使用时直接打开 `index.html`，无需安装依赖或连接外部服务。

## 数据范围

- 77 份标准、规范、图集及政策目录
- 258 条结构化要求
- 重点覆盖 GB 50174-2017、GB/T 44989-2024、GB/T 33136-2024、GB/T 43331-2023、GB 40879-2021、GB 50462、GB/T 2887、GB 9361 等核心标准

## 本地验证

```powershell
node --check build_data_center_requirements.js
node build_data_center_requirements.js
node test_data_center_requirements.js
```
